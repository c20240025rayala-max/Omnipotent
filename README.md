# Omnipotent

Omnipotent is a responsive web development studio website built with Astro and GSAP.

## Pages

- `/` — Home
- `/about/` — About Omnipotent
- `/services/` — Services
- `/process/` — Our process
- `/projects/` — Selected projects
- `/contact/` — Contact

The portfolio cards are clearly labeled concept work. The project inquiry form prepares an email in the visitor's default email app; it does not send data to a server.

## Commands

Run the Astro development server:

```sh
npm run dev
```

Check Astro and TypeScript diagnostics:

```sh
npm run check
```

Build the static site:

```sh
npm run build
```

Build and serve the static site with Live Server on port 5500:

```sh
npm run live
```
